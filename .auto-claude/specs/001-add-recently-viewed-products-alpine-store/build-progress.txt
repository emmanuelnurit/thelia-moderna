## Key Discoveries

### Existing Patterns to Follow:
1. **Wishlist Store Pattern** (assets/js/app.js lines 47-220):
   - Uses `Alpine.$persist([]).as('moderna_wishlist')` for local persistence
   - Product data structure: id, title, url, image, imageId, price, promoPrice, isPromo
   - Methods: has(), toggle(), add(), remove(), clear(), count getter
   - Dispatches events: wishlist:added, wishlist:removed, wishlist:cleared
   - Exposed via window.Moderna.wishlist helpers

2. **Product Data Available** (product.html.twig):
   - product.id, product.i18ns.title, product.publicUrl
   - initialImageId for image reference
   - taxedPrice, taxedPromoPrice for formatted prices
   - currentPse.promo for promo status

3. **Component Patterns** (components/Product/, wishlist.html.twig):
   - Twig components with inline styles
   - Alpine.js x-data for state management
   - Responsive grid layouts
   - Event listeners for store changes
