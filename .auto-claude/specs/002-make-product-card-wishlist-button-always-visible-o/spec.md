# Make Product Card Wishlist Button Always Visible on Touch

## Overview

The wishlist button on product cards has opacity: 0 by default and only appears on hover. This makes it inaccessible on touch devices where there's no hover state.

## Rationale

Touch device users cannot see or interact with the wishlist button since :hover doesn't trigger on tap. This breaks a key e-commerce feature for a significant user segment.
