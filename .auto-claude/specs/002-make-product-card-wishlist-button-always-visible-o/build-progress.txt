# Build Progress: Make Product Card Wishlist Button Always Visible on Touch

## Status: Implementation in Progress

## Summary
Implementation started. Added media query to make wishlist button visible on touch devices.

## Problem Analysis
- File: `assets/css/components/_product-card.css`
- The `.product-card-wishlistBtn` has `opacity: 0` by default (line 107)
- It only becomes visible on `.product-card:hover` (lines 114-117)
- Touch devices don't support `:hover`, making the button inaccessible

## Solution
Add a CSS media query `@media (hover: none)` to always show the button on touch devices.
